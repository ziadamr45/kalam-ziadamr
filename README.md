# كلام له لازمة — المنصة العامة

> **مش كل كلام لازم يتقال.. بس فيه كلام له لازمة.**

المنصة الفكرية والمعرفية العربية — واجهة قراءة نقية، بلا إعلانات، بلا ضجيج، مع هندسة طباعة عربية فاخرة ومميزات تفاعلية متكاملة.

---

## الميزات الكاملة

| المحور | التنفيذ |
|--------|---------|
| **تجربة التركيز والهدوء** | واجهة زن نقية بلا مشتتات، إخفاء تلقائي سلس للقوائم عند التمرير لأسفل وإعادتها عند الصعود، «وضع الغمر الكامل» يخفي كل شيء عدا المقال، تمرير انسيابي وتأثيرات ميكروية بإحساس التطبيقات الأصلية |
| **هندسة الطباعة العربية** | خط Amiri لجسم المقالات (يبرز التشكيل بوضوح فائق) وReadex Pro للواجهة، نسب ارتفاع سطر مرتفعة لاستيعاب الحركات، نسخة مشكولة بحجم أكبر وأرحب |
| **الثيم الذكي** | وضع ورقي فاتح افتراضي + وضع ليلي عميق، حفظ التفضيل في LocalStorage وCookies، **صفر وميض** أثناء التحميل (سكربت ما قبل الترطيب) |
| **مفتاح التشكيل** | زر تبديل انسيابي أعلى كل مقال يبدّل آنيًا بين النسخة القياسية والنسخة المشكولة المخزنة مسبقًا — بلا إعادة تحميل، وحفظ تفضيل القارئ |
| **محرك وقت القراءة العربي** | خوارزمية متخصصة (180–200 كلمة/دقيقة، افتراضي 190) + زمن تأمل الاقتباسات والعناوين، عرض بصيغة عربية سليمة: «مدة القراءة المتوقعة: ٤ دقائق مركزة» |
| **شريط تقدم القراءة** | شريط نحاسي أعلى الصفحة يتدرج بنعومة مع حركة القارئ |
| **مولد بطاقات الاقتباس** | ظلّل أي جملة → زر «اقتباسها» → بطاقة جرافيكية فخمة (ثيم ورقي/ليلي × مقاسات ستوري/إنستجرام/إكس) جاهزة للتحميل أو المشاركة بضغطة زر |
| **المشغل الصوتي المزامن** | مشغل خفيف: تشغيل/إيقاف، ±١٠ ثوانٍ، سرعات ١×/١.٢٥×/١.٥×، **إبراز الفقرة المقروءة آنيًا** (توقيتات يدوية أو توزيع تناسبي تلقائي) مع تتبع تمرير اختياري |
| **المختصر المفيد** | حقل ملخص يدوي من لوحة التحكم يعرض كنقاط مكثفة قابلة للطي |
| **التفاعل الذكي** | أعجبني/لم يعجبني بتحديث تفاؤلي فوري بلا إعادة تحميل، تصويت واحد لكل زائر (بصمة/حساب)، إلغاء التصويت بالنقر مجددًا، منع التلاعب |
| **الفلترة الأخلاقية** | 3 مستويات: Blocklist لحظي (Regex) + فحص قيم وشريعة + مكافحة سبام، فحص فوري قبل الإرسال على العميل وفرض نهائي على الخادم |
| **الإبلاغ المجتمعي** | زر إبلاغ لكل تعليق بأسباب محددة، 3 إبلاغات → رفع أولوية المراجعة في لوحة التحكم |
| **Google OAuth** | دخول بحساب Google (Auth.js v5) للتعليق والتفاعل — الدليل: `GOOGLE_OAUTH_GUIDE.md` |
| **PWA + أوفلاين** | تثبيت كتطبيق على الهاتف والكمبيوتر، حفظ المقالات في IndexedDB للقراءة دون اتصال، صفحة /saved تعمل بلا شبكة |
| **الأداء** | ISR (إعادة تحقق كل 5 دقائق + On-Demand فوري عند النشر)، Server Components، ميتاداتا وOpenGraph وSitemap وJSON-LD كاملة |

## الأقسام (تسمية غير مألوفة)

- **الأثر** — أفكار تركت أثرًا.. وتستحق أن تُطبَّق لا أن تُقرأ فقط
- **زوايا رؤية** — قراءة مختلفة لما نعيشه كل يوم
- **موازين** — نزِن القرارات والقيم بعين صافية
- **أفكار للتطبيق** — أفكار عملية جاهزة للتنفيذ فورًا

## المكدس التقني

- **Next.js 15** (App Router, Server Components, ISR) + **React 19** + TypeScript
- **PostgreSQL** + **Prisma ORM**
- **Auth.js v5** (Google Provider)
- **Tailwind CSS** + خطا Amiri وReadex Pro عبر next/font
- Service Worker مكتوب يدويًا (بلا اعتماديات) + IndexedDB (idb-keyval)

## التشغيل المحلي

```bash
# 1. نسخ متغيرات البيئة وملؤها (انظر الجدول أدناه)
cp .env.example .env.local

# 2. تثبيت الاعتماديات (يشمل prisma generate تلقائيًا)
npm install

# 3. التشغيل
npm run dev
```

> قاعدة البيانات تُدار وتُزرع من **لوحة التحكم** (`kalam-admin-ziadamr`) — المشروعان يتشاركان نفس `DATABASE_URL`.

## متغيرات البيئة

| المتغير | الوصف |
|---------|-------|
| `DATABASE_URL` | رابط PostgreSQL (Neon / Supabase / Vercel Postgres) — **نفسه في لوحة التحكم** |
| `NEXTAUTH_URL` | رابط الموقع النهائي |
| `NEXTAUTH_SECRET` | سلسلة عشوائية: `openssl rand -base64 32` |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | من Google Cloud Console — الدليل خطوة بخطوة في `GOOGLE_OAUTH_GUIDE.md` |
| `NEXT_PUBLIC_SITE_URL` | الرابط العام للموقع |
| `REVALIDATE_SECRET` | سر إعادة التحقق الفوري — **نفسه في لوحة التحكم** |

## النشر على Vercel

1. ارفع المستودع ثم: **Vercel → Add New Project → Import** هذا المستودع.
2. أدخل متغيرات البيئة أعلاه في **Settings → Environment Variables**.
3. Build Command الافتراضي يعمل كما هو (`prisma generate && next build`).
4. بعد نشر لوحة التحكم، أي مقال يُنشر من هناك سيستدعي `/api/revalidate` فتتحدث المنصة **فورًا**.

## البنية

```
src/
├── app/                    # الصفحات (App Router)
│   ├── page.tsx            # الرئيسية (ISR)
│   ├── article/[slug]/     # صفحة المقال الكاملة
│   ├── section/[slug]/     # صفحات الأقسام
│   ├── saved/              # القراءات المحفوظة (أوفلاين)
│   ├── about/              # الفلسفة ومعايير النشر
│   └── api/                # interactions, comments, analytics, revalidate, auth
├── components/             # القارئ التفاعلي، المشغل الصوتي، الاقتباسات، التعليقات..
├── lib/                    # الفلترة الأخلاقية، محرك وقت القراءة، IndexedDB, Auth
└── types/
public/sw.js               # Service Worker للقراءة دون اتصال
```
